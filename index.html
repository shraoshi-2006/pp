About Me & What I Care About

Curious about what happens under the hood — from network packets and endpoint security to clean software architecture.

I am an undergraduate student pursuing my B.Sc. in Cyber Security at Guru Nanak Institute of Technology (MAKAUT) in Kolkata.

My interest in computing started with wanting to understand how systems actually work behind the screen. Instead of just learning frontend interfaces or memorizing textbook definitions, I got hooked on understanding protocols: how data travels across ports, where applications leak information, and how software can be designed defensively to prevent common vulnerabilities.

I learn best by building real software. Whether it's writing an autonomous vulnerability assessment platform like NetSentinel, crafting a real-time password entropy evaluator, or building full-stack web systems with Next.js and FastAPI, I focus on practical implementation, clean code, and defensive hygiene.

When I'm not coding or studying course material, you'll find me exploring web security advisories, testing open-source security utilities, or learning about incident response and digital forensics workflows.

01

NetSentinel

Network Vulnerability Assessment & Security Posture Management Platform

I built NetSentinel to make network security audits understandable and practical for developers and security learners. Rather than relying on confusing terminal dumps, NetSentinel runs automated socket checks and deep Nmap service fingerprinting, examines HTTP security headers, and calculates a clear 100-point security posture score with actionable fixes.

Dual-Engine Scanning

Fast Python socket pre-scans paired with deep Nmap service & port fingerprinting.

100-Point Score Model

Transparent scoring across ports, exposed services, headers, and known risk vectors.

Session Isolation

Client-side session separation via X-User-ID to prevent cross-user audit leakage.

Remediation & Export

Actionable remediation tips with one-click structured JSON audit export.
